# ADR-0003. Хранение вложений TimeCapsule

**Статус:** принято для ЛР4.

## Контекст

В предыдущей версии PostgreSQL хранит метаданные капсул, а вложения лежат на диске приложения. При замене EC2 или добавлении второго сервера файлы должны оставаться доступными по тем же ключам. Доступ к содержимому должен зависеть от правил TimeCapsule.

## Варианты

| Хранилище | Преимущества | Ограничения |
| --- | --- | --- |
| EBS сервера | Простой локальный путь и обычные файловые операции | Для переноса на другой узел нужен отдельный перенос или восстановление тома. Общая копия вложений для нескольких серверов отдельно не появляется. |
| Amazon EFS | Общая файловая система для нескольких EC2, привычные файловые операции | Требуются монтирование и настройка сети. В обычной схеме приложение само читает и отдаёт файл. |
| Amazon S3 | Независимое объектное хранилище, прямое скачивание по подписанному URL и история версий | Приложению нужен SDK. Затраты учитывают хранение объектов, запросы и передачу данных. |

## Решение

Вложения хранятся под `uploads/` в закрытом бакете Amazon S3. PostgreSQL по-прежнему хранит метаданные, а авторизацию на скачивание проверяет TimeCapsule. EC2 получает временные учётные данные через IAM instance profile.

## Последствия

- После проверки прав приложение возвращает HTTP 302. Браузер скачивает объект из S3 по HTTPS. Подпись действует пять минут или до более раннего истечения учётных данных роли. Ссылка даёт доступ предъявителю в пределах её срока и подписанного запроса.
- Удаление объекта по ключу создаёт маркер. Роль не может удалять конкретные версии. Правило жизненного цикла ограничивает рост старых версий и удаляет брошенные части загрузок.
- Несколько серверов приложения за балансировщиком могут писать в тот же бакет и подписывать запросы к тем же объектам. Для локальных сессий потребуется отдельное общее хранилище.
- При требовании пережить потерю региона нужны копия объектов и план переключения на второй регион. Репликацию следует согласовать с восстановлением PostgreSQL и политиками доступа.
